# Cloud Spanner Graph Plugins

This directory contains the publishable Backstage plugins for Google Cloud Spanner Graph:

- [`catalog-backend-module-spanner-sync`](./catalog-backend-module-spanner-sync): Synchronizes Backstage catalog entities and relationships into Cloud Spanner Graph.
- [`spanner-graph-backend`](./spanner-graph-backend): Executes parameterized ISO GQL subgraph and blast-radius queries against Cloud Spanner Graph.
- [`spanner-graph`](./spanner-graph): Renders interactive multi-hop dependency cards, full-screen topology explorers, and natural-language graph search cards in Backstage.
